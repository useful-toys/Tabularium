- Decisão: figurinhas aparecem só por código, nome e seção; nenhuma imagem dos cromos
- Contexto: as imagens são protegidas por direitos autorais da Panini, e o projeto é independente
- Alternativas descartadas
  - Imagens enviadas pelos usuários: mesmo problema de direitos, agora distribuído
  - Imagens licenciadas: sem viabilidade para um projeto sem receita
- Consequências
  - Ganha: projeto livre de risco jurídico
  - Aceita: identificação só pelo texto; o usuário confere no álbum físico
