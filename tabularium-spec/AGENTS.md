# tabularium-spec

Spec do próprio tabularium3, isto é, do template. Não confunda com `spec/`, que é o exemplo entregue a quem adota o template.

- Segue as mesmas regras de `spec/AGENTS.md`. Leia esse arquivo antes de editar aqui.
- Aqui, "código" é o que o template entrega: `AGENTS.md`, `spec/AGENTS.md`, `scripts/`, `.claude/skills/`, `.github/`.
- Comandos: `node scripts/spec.mjs build-map --spec tabularium-spec` e `node scripts/spec.mjs check --spec tabularium-spec`.
- Quem adota o template apaga esta pasta.
